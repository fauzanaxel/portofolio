Proyek Saya

Beberapa karya terbaik saya

XolveS

Work Management System atau XolveS merupakan aplikasi berbasis web yang dirancang untuk membantu tim dalam mengelola tugas, proyek, dan aktivitas kerja secara terstruktur. Sistem ini menyediakan fitur seperti pembuatan dan pembagian tugas, penentuan deadline, penugasan anggota, filter berdasarkan proyek, serta role-based access control. Proyek ini dikembangkan untuk meningkatkan koordinasi, efisiensi, dan transparansi dalam pengelolaan pekerjaan tim.

CODETAX

Aplikasi desktop berbasis C# .NET dan SQLite yang dirancang untuk membantu pengelolaan data perpajakan secara terstruktur. Sistem ini mencakup fitur pengelolaan wajib pajak, dokumen, pembayaran, serta laporan dengan antarmuka yang sederhana dan mudah digunakan.

Smart Clock Temperature Logger

Smart Clock Temperature Logger merupakan proyek sistem monitoring suhu berbasis ESP32 dan sensor DHT22 yang dirancang untuk mengukur, mencatat, dan memantau kondisi suhu secara real-time. Sistem ini mengintegrasikan perangkat keras dengan web monitoring sehingga data suhu dan waktu dapat ditampilkan dan dipantau dengan lebih mudah. Proyek ini dikembangkan untuk memahami penerapan Internet of Things (IoT), komunikasi antara mikrokontroler dan sistem web, serta proses pembacaan dan pengolahan data sensor..
